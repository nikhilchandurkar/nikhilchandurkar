## Projects

### 🏦 Data Marketplace — Django, DRF, MySQL *(work)*
Central API service for a loan origination system covering PAN, Aadhaar (OTP, OTP-less, DigiLocker), driving licence, voter ID, passport, RC, Udyam, GST, Form 26AS, ITR analytics, court-case, PEP, and AML checks. Includes OCR and masking APIs (PaddleOCR, GLM-OCR) for Aadhaar, PAN, Form 16, salary slips, and more, plus per-bank usage and pricing tracking for billing.

### 📊 Bank Statement Analysis — Python, Django, Celery, Redis, PostgreSQL *(work)*
APIs that turn PDF and scanned statements into structured transaction data and analytics (EOD balance, 50+ filters). Uses Celery for async processing, Redis for low-latency recent reports, and bank-specific alert rules such as repeated cheque bounces.
